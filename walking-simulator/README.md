# Harmony Walking Simulator

Apri `index.html` tramite server locale, oppure usa l'URL già avviato:

`http://127.0.0.1:48321/`

Controlli: `A/D` o frecce per camminare, `Spazio` per alternare Sovraccarico/Harmony, `Escape` per mettere in pausa/riprendere, `Invio` per chiudere le cutscene.

Audio: inserisci nella cartella `assets/` i file `basso.mp3`, `melodia.mp3`, `pad.mp3`. In alternativa vengono cercati anche `track_1.mp3`, `track_2.mp3`, `track_3.mp3`. Se mancano, il gioco usa layer sintetici di fallback.
